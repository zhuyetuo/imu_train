# 特征工程说明

`src/ml/features.py` 对每个时间窗口（默认2秒，16Hz采样即32个数据点）提取手工特征，供随机森林等传统机器学习模型使用。

## 输入

6个传感器通道：
```
acc_x, acc_y, acc_z   ← 三轴加速度（重力对齐后）
gyr_x, gyr_y, gyr_z   ← 三轴角速度（陀螺仪）
```

每个通道独立提取 **9个时域特征 + 4个频域特征 = 13个特征**，6个通道共 **78个特征**（对应日志中"特征维度: 78"）。

---

## 时域特征（每通道9个）

| 特征 | 计算方式 | 物理意义 |
|---|---|---|
| **均值 (mean)** | 窗口内数值平均 | 该轴的整体倾向。加速度均值反映姿态方向（如趴着 vs 站立时哪个轴受重力影响大）；角速度均值接近0是静止，偏离0说明持续朝一个方向转动 |
| **标准差 (std)** | 窗口内数值波动程度 | **运动剧烈程度的核心指标**。抓挠时肢体快速抖动，std会明显高于睡觉（几乎不动）和一般活动（相对平稳的位移） |
| **最小值 (min)** | 窗口内最小值 | 配合最大值反映极端姿态/角速度 |
| **最大值 (max)** | 窗口内最大值 | 同上，抓挠动作的瞬时峰值通常很高（爪子快速摆动的加速度冲击） |
| **极差 (max-min)** | 最大值减最小值 | **动作幅度**。抓挠是小范围高频动作，极差可能比大幅度奔跑小，但比睡觉大很多 |
| **均方根 (RMS)** | √(平均值²) | 能量强度的稳健度量，比std更能反映"整体运动能量"，不受均值偏移影响 |
| **偏度 (skewness)** | 分布的不对称程度 | 抓挠动作是间歇性的（抓一下停一下），信号分布可能左右不对称；持续平稳的活动（如走路）偏度较小 |
| **峰度 (kurtosis)** | 分布的尖锐程度 | **区分"间歇性剧烈动作"与"持续性动作"的关键特征**。抓挠是短促爆发式动作，信号中会出现少数几个尖锐峰值，峰度高；平稳走动峰度低 |
| **过零率 (zero crossing rate)** | 信号穿越0点（或均值）的次数 | **反映动作的"抖动频率"**。抓挠时爪子快速来回摆动，加速度/角速度会频繁正负交替，过零率显著高于睡觉或缓慢活动 |

## 频域特征（每通道4个）

先用 Welch方法 计算功率谱密度（PSD），再提取：

| 特征 | 计算方式 | 物理意义 |
|---|---|---|
| **频谱均值 (spectral mean)** | 各频率按功率加权平均 | 信号的"平均振动频率"。抓挠是快速重复动作，能量集中在较高频率；睡觉时信号能量集中在极低频（接近静止） |
| **频谱标准差 (spectral std)** | 频率分布的离散程度 | 频率成分是否集中。抓挠这种规律性重复动作，频谱可能相对集中在某个频段附近；随机的一般活动频谱更分散 |
| **主频 (dominant frequency)** | 功率谱密度最大值对应的频率 | **最关键的判别特征之一**。狗抓挠通常有稳定的重复节律（类似"抓-抓-抓"的固定频率，一般在3-8Hz左右），这个主频与走路/摇尾巴等其他周期性动作的频率不同，是区分行为类别的强特征 |
| **频谱熵 (spectral entropy)** | 功率谱分布的信息熵 | 能量分布是否规律。**熵越低说明能量集中在少数频率上（有规律的重复动作，如抓挠、走路）；熵越高说明能量分散（随机/不规则运动，或者是噪声）**。睡觉时熵通常很低（几乎无能量，或能量在极低频） |

---

## 为什么这套特征能区分"活动 / 睡觉 / 抓挠"

| 行为 | 加速度std/RMS | 过零率 | 主频 | 频谱熵 |
|---|---|---|---|---|
| **睡觉** | 很低（几乎静止） | 很低 | 接近0Hz | 很低（能量集中在直流分量） |
| **活动**（走动、玩耍等） | 中到高，但相对平稳 | 中等 | 较低且分散（步态频率通常1-3Hz） | 中等 |
| **抓挠** | 高且带有突发峰值（峰度高） | 高（快速抖动） | 集中在特定较高频段（3-8Hz左右的重复节律） | 较低（规律性强，但和活动的规律性不同频段） |

模型（随机森林）本质上是在这78维特征空间里，学习出能把"抓挠"从"活动"和"睡觉"里分离出来的决策边界。**峰度、过零率、主频、频谱熵这几个特征通常是区分抓挠与普通活动的最关键因子**——因为它们捕捉的是"短促、高频、有规律重复"这个抓挠动作的本质特征，而不仅仅是"运动幅度大小"（这一点均值/极差等无法区分抓挠和奔跑等同样剧烈的活动）。

## 已知局限

1. **窗口固定2秒**：如果单次抓挠动作持续时间明显短于或长于2秒，窗口内会混入其他行为的信号，稀释特征的判别力
2. **6通道等权重提取**：目前每个通道独立提取相同的13个特征，没有显式建模三轴之间的相关性（例如抓挠动作在某个特定轴上更明显，另一轴主要是姿态噪声）
3. **重力对齐依赖姿态估计准确性**：如果重力对齐（`gravity_align`）有误差，会直接影响均值等依赖绝对方向的特征
