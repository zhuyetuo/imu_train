狗狗戴上项圈，就能知道它的皮肤和毛发怎么样

皮肤问题（过敏、皮炎、真菌感染等）最早的信号是抓挠变多。项目分两步：第一步从项圈 IMU 里认出抓挠、舔、啃、蹭等行为；第二步把每天的行为事件和主人填的问卷合起来，评估皮肤状态，给出“正常 / 留意 / 建议看兽医”三档。
