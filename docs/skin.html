第二步 · 皮肤评估 · 更新于 2026-11-17

把每天的抓挠，变成“皮肤正常 / 留意 / 建议看兽医”

输入是第一步给出的抓挠事件，加上主人填的问卷（皮肤颜色、异味、皮损、秃毛、毛发状态），以后还有照片。输出两个分：C 值只看行为，S 总分把行为、皮肤、毛发合在一起。对外只展示三档，不展示分数，文案只说“检测到变化 / 建议咨询兽医”，不说“诊断”。

怎么算

抓挠事件来自第一步，只算戴着的时段，人工核对过的片段优先
日统计次数、时长、每佩戴小时、夜间占比、扎堆程度、被抓醒
跟自己比14 天中位数基线；满 21 天前用文献阈值兜底

算法模块和进展

PM 规则版已上线

C 值 / S 总分

按产品《算法定义文档 V0.4》实现，问卷分组加权。平台上可以整批算、出周报表，跟兽医评级对照。

个人基线已实现，待验证

14 天 中位数；满 21 天启用

PM 文档里留白的部分由算法侧补上。冷启动期用 Whistle FIT 公开的抓挠参考值兜底。参数都还要用真实数据校准。

模型 A（行为）合成数据

44 个 IMU 特征 → C 档

频率 / 时长、时间分布、跟基线比、滚动趋势、发作史。标签是 PM 规则算出来的 C 档，本质是规则的近似，好处是能解释每个特征的贡献。

模型 B（综合）等真实标签

54 个特征 → S 档

模型 A 的 44 个 + A 的预测 3 个 + 问卷 7 个。S0/S1/S2 跟兽医看照片的评级一一对应；评级攒够后用真实标签重训，交叉验证比 PM 规则准才启用。

分层贝叶斯合成数据验证过

品种 → 狗 → 天

两版：对兽医有序评级建模；直接对抓挠次数建模（不要兽医标签）。新狗能借同品种的数据，并给出不确定性。现在 4 只影棚狗品种都不一样，群体层还没意义。

模型 C：照片看皮肤方案阶段

IMU × 视觉

抓得多不等于皮肤差，抓得少也可能已经有问题（疼得不敢抓、部位不痒）。照片检测皮损 / 秃毛，和 IMU 两路互相印证。检测类别要兽医确认。

数据现状

现在只有 4 只影棚狗、每只几天到几周的历史，兽医照片评级还在攒。所以模型 A / B 只在合成数据上训过，平台上显示的模型结果只能看方向，不能当准确率。真正能验证的是：PM 规则的四个子分和兽医判断的方向是否一致。
