把每天的抓挠，变成“皮肤正常 / 留意 / 建议看兽医”

输入是第一步的抓挠事件 + 主人填的问卷（以后还有照片）。输出两个分：C 值只看行为，S 总分把行为、皮肤、毛发合在一起。对外只给三档，文案只说“检测到变化 / 建议咨询兽医”，不说“诊断”。
