11-18 新提的 7 个方向

1. 陀螺仪按需开试过：不用

开 18% 的时间只追回 1.5 个点；陀螺仪要攒满 8 s 才能用，多数抓挠只有几秒。主力用 3 轴。

2. 加速度计智能开关值得做

戴着的时间约六成在睡 / 静止：静止时降采样或用运动唤醒中断让主控睡。下一步：板上状态机 + 实测电流。

3. 原始 IMU 压缩上传有数了

3 轴 10.4 MB/天 → 差分 + Rice 无损 4.3 MB；只传疑似事件前后 0.36 MB。有损量化对识别没影响。

4. 变采样率有数了

3 轴 31.25 Hz 命中 88.1% 最高，10 Hz 掉到 81.5%。策略：静止 10–12.5 Hz、活动 25–31.25 Hz。

5. CMSIS-NN 算子有结论

只换算子不换框架：宿主机快 2.9×，Flash +7 KB、RAM +5 KB，输出一致。待上板实测。

6. 流式增量卷积可以做

不补零的结构精度不掉，计算省 6–8 倍；要改步长、导出和板上推理，2–3 天。

7. 皮肤评估数据不跟着标注变查到原因

日统计不自动重算；照片评级账号没勾「兽医」系统不认；AI 版还在用 8 月老模型。前两项等你操作。
